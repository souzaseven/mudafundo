# 🖼️ Removedor de Fundo de Imagem

<img src="https://github.com/souzaseven/mudafundo/blob/Desafios/Muda%20cor%20de%20fundo/cachorrofundo.png?raw=true" width="30%" alt="Preview">

Ferramenta web para remoção de fundo de imagens e personalização com novos fundos coloridos ou imagens.

## ✨ Funcionalidades

### 🔄 Processamento de Imagens
- **Remoção de fundo** via API Remove.bg
- **Visualização em tempo real** das alterações
- **Multiplos formatos** de saída (PNG, JPG)

### 🎨 Personalização
- **Novos fundos**:
  - Cores sólidas (seletor de cores)
  - Imagens personalizadas
- **Comparação lado a lado**:
  - Original vs Processada
  - Com novo fundo
